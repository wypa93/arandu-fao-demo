# ASTA Suriname · Pineapple Pilot Monitor (mockup)

Interactive dashboard mockup for discussing the FAO Suriname pineapple pilot with arandu.

- Live: https://wypa93.github.io/arandu-fao-demo/
- Start the guided demo: https://wypa93.github.io/arandu-fao-demo/#tour
- Prioritized use cases: https://wypa93.github.io/arandu-fao-demo/#usecases

All fields, farmers and usage figures are simulated. Satellite availability figures come from a
12-month Sentinel-2 / Sentinel-1 replay over two pilot-area sites.
